Two things this tier deliberately does not hide.
--ui-opacity-disabled .6
--ui-opacity-locked .5		Production ships two opacities for what looks like one idea. They are tokenised separately and named for their cause, because a rate limit and an eligibility gate may genuinely differ. A tier that averaged them would have buried a live question.
--ui-focus-ringThe only value here that is not evidence. No focus treatment exists in production. Defined so components have something to bind; phase 7 owns the rule.

And one contradiction it exposes. brand.css already carried a Figma-derived alias block in which --sc-action-primary is green #019035. The shipping AppButton renders gold #edb843 on navy. Per D-001 the code wins — but per D-005 a token is never silently rewritten, so the Figma aliases are untouched and flagged for a human. That disagreement had been sitting in the system since phase 1, invisible, because nothing consumed either value.
