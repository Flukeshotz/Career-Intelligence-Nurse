Bottom bar — the five slots

One bar on every shell route. Only three slots navigate.

Home
Always /. The German Practice hub is the home screen — there is no separate home.
Jobs
A1/A2 → /jobs (locked gate). B1/B2 → /job-screening, and the tap also persists lg_preferred_mode = job_screening.
Centre arch
Not a tab. A raised dome with the German flag and a two-line caption. Tappable only in Guided German → /learn-german/recap; inert elsewhere.
Coins
Read-out only, synced from /user/me. Never navigates.
Streak
Fires openLeaderboard — opens the streak leaderboard sheet. Not a route.

Header: the level title is a brand link back to the active hub; the 28px avatar goes to /profile. On /scholarship every slot but Home greys out.

Top mode switcher — who gets which tabs

Derived from the route, not from stored state. Active tab melts into the page colour below it.

Below B1
Guided German /learn-german · German Practice / · German Classes /video-courses (behind the german_classes flag).
B1 & B2
Two tabs only: Job Preparation / · German Jobs /job-screening. No Guided German, no Classes.
Scholarship
One static tab, "Scholarship Exam". The candidate cannot leave the funnel from the chrome.
