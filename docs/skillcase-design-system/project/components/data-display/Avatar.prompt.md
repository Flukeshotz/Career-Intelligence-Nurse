# Avatar

Learner or coach avatar with optional status icon.

```jsx
<Avatar size="xs" statusIcon="false" text1="Label" />
```

Variants: `size` (xs, sm, md, lg, xl, 2xl) · `statusIcon` (false, online indicator, company, verified)

Text slots (`text1`…) override the design's baked copy; see the `.d.ts` for defaults.
