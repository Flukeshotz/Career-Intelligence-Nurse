# CheckItem

Intentional addition (no Figma component set; ported from the shipping app code). A benefit line with a round tick well — the paywall and plan screens are built from stacks of these.

```jsx
<CheckItem variant="dark">TELC &amp; Goethe past papers</CheckItem>
```

Variants: light (grey well, navy tick) · dark (navy well, gold tick, 80% white copy — for navy panels) · accent.
