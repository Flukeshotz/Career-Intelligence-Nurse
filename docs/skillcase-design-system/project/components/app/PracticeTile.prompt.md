# PracticeTile

Intentional addition (no Figma component set; built from the live app). The German Practice grid tile — photo strip, title, one-line caption.

```jsx
<PracticeTile title="Flashcards" caption="Learn image-based vocabulary with quiz checkpoints" image="/assets/img/practice/flashcards.webp" />
```

108px wide so three fit a row with 10px gaps inside the 16px gutter. Live set: Flashcards · Grammar · Listening · Speaking · Reading · Test · News.
