# AppBadge

Intentional addition (no Figma component set; ported from the shipping app code). Small status pill for plan and lesson state, with an optional pinging dot.

```jsx
<AppBadge variant="success" dot>Active</AppBadge>
```

Variants: success (#cdf5db/#019035) · warning (#ffebbe/#c48b0e) · neutral. 10px medium, full radius.
