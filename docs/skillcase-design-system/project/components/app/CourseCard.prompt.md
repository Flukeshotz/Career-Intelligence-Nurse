# CourseCard

Intentional addition (no Figma component set; built from the live app). The German Classes course row — thumbnail, level and difficulty chips, progress track.

```jsx
<CourseCard title="German for Beginners 🇩🇪" level="A1" difficulty="Easy" completed={0} total={7} image="/assets/img/geothe.webp" />
```

Full-width, radius 12, 1px #e5e7eb border. The progress track fills navy; the caption always reads "n/m videos completed".
