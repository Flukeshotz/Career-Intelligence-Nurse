# Tag

Filter/selection tag for topics and specialisations.

```jsx
<Tag size="sm" icon="false" text1="Label" />
```

Variants: `size` (sm, md, lg) · `icon` (false, country, avatar, dot) · `action` (x close, text only, count)

Text slots (`text1`…) override the design's baked copy; see the `.d.ts` for defaults.
