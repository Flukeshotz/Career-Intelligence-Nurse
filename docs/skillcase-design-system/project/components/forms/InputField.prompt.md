# InputField

Text input with label, hint, states and seven leading/trailing types.

```jsx
<InputField size="sm" type="default" text1="Label" />
```

Variants: `size` (sm, md) · `type` (default, leading dropdown, trailing dropdown, leading text, payment input, tags, trailing button) · `state` (placeholder, filled, focused, disabled)

Text slots (`text1`…) override the design's baked copy; see the `.d.ts` for defaults.
